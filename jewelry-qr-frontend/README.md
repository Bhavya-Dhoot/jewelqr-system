# Jewelry QR System - Frontend Prototype

## Overview
Interactive HTML/CSS/JavaScript prototype for the Jewelry QR Composition, Cloud Inventory & Dynamic Pricing System.

## Features
- ✅ CREATE Interface (Desktop-optimized)
- ✅ SCAN Interface (Mobile-optimized)
- ✅ Admin Dashboard
- ✅ Bulk QR Generation
- ✅ Analytics & Reporting
- ✅ Settings Management

## Technology Stack
- **HTML5** - Semantic markup
- **Vanilla CSS** - Custom design system
- **JavaScript (ES6+)** - Interactive functionality
- **QR Code Library** - qrcode.js for generation
- **Camera API** - html5-qrcode for scanning

## Quick Start

### Local Development
```bash
# Navigate to project directory
cd jewelry-qr-frontend

# Open in browser (use Live Server or similar)
# Main pages:
# - index.html (Landing/Navigation)
# - create.html (CREATE interface)
# - scan.html (SCAN interface)
# - dashboard.html (Admin Dashboard)
# - bulk-qr.html (Bulk Generation)
# - analytics.html (Analytics)
# - settings.html (Settings)
```
